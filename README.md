# Equifax Data Breach Analysis (2017)

## Overview
This project analyses the 2017 Equifax data breach, one of the largest cybersecurity incidents affecting over 147 million individuals.

## Objectives
- Evaluate governance and internal control failures
- Assess data, systemic, and regulatory risks
- Provide recommendations to improve accountability and resilience

## Key Insights
- Failure to patch known vulnerabilities led to major system compromise
- Weak internal controls and delayed response increased impact
- Highlighted the importance of strong governance and cybersecurity practices

## Skills Demonstrated
- Critical thinking and risk analysis  
- Governance and accountability assessment  
- Data and system risk evaluation  
- Policy and recommendation development

- FinTech Risk Framework
